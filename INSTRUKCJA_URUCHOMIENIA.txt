WOJNA PASTWISK v2 - PODMIANA NA GITHUB/RENDER

1. Rozpakuj paczke.
2. W repozytorium GitHub nadpisz WSZYSTKIE stare pliki zawartoscia folderu wojna-pastwisk.
3. Nie wgrywaj samego ZIP-a. W katalogu glownym repo musza byc package.json i server.js.
4. Zapisz zmiany przez Commit changes.
5. Render powinien wdrozyc commit automatycznie.
6. Jesli nie: Render -> Manual Deploy -> Deploy latest commit.
7. Po wdrozeniu odswiez gre przez Ctrl+F5.
